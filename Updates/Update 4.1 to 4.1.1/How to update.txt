==========================================================
== If you running Sngine v 4.1 you can upgrade to 4.1.1 ==
==========================================================

!!! IMPORTANT !!!
==============================================================================================================
== Backup your database and your website files just in case something wrong happened                        ==
==============================================================================================================

1- Shutdown your system from the admin panel

2- Upload all files located in the "Update_4.1.1" folder to your live server and replace all files/folders inside this folder

3- Empty this folder "content/themes/default/templates_compiled"

=========================================================
== After Update ==
=========================================================

1- Only for Cloudflare users, Don't forget to flush your website cache from Cloudflare

2- Go to your admin panel (http://yourdomain.com/path_to_script/admincp) and make site live again

And That's it, Have Fun :)
